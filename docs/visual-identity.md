# 觀測終端視覺規範

《天才模擬器》的主視覺。所有畫面都是**同一台機器**的不同分頁——玩家不是在看一款遊戲的選單，而是在操作「全球超譯協會」配發的觀測終端。

這份規範的來源是開機序列的視覺，往外貫徹到整個產品。

---

## 一、核心概念

> 介面本身就是虛構物。

不是「通往世界的入口」，而是**世界裡的一件器材**。判斷任何新元件是否合格，只問一句：

**這個東西，在遊戲的世界裡真的會存在嗎？**

- 「設定」不存在 → 「終端校準」存在
- 「成就列表」不存在 → 「已認定事蹟」存在
- 「關閉」不存在 → `[[ 關閉 ]]` 這種下給機器的指令存在

## 二、色彩

### 2.1 外殼（磷光通道）

終端本身的顏色。所有框架、標題、指令、讀數都用這組。

| Token | 色值 | 用途 |
|---|---|---|
| `--term-bg` | `#060a08` | 最底層背景 |
| `--term-bg-2` | `#0b1410` | 面板底 |
| `--term-bg-3` | `#12201a` | 浮起的區塊、卡片 |
| `--term-line` | `#1e3b2c` | 分隔線、邊框 |
| `--term-fg` | `#7ef0a8` | 主要磷光文字 |
| `--term-dim` | `#5f9c78` | 次要文字、標籤 |
| `--term-bright` | `#d8ffe8` | 內文、強調 |

### 2.2 訊號通道

不是裝飾，是**語意**。每個顏色只做一件事。

| Token | 色值 | 語意 |
|---|---|---|
| `--gold` | `#ffd23f` | 協會核定 · 權威 · 重要數值 |
| `--cyan` | `#3fe6e0` | 工程 · 基地 · 建設 |
| `--danger` | `#ff5f56` | 警告 · 風險 · 失敗 |

### 2.3 學派通道（資料色）

**這組不受外殼影響。** 終端的外殼是單色磷光，資料才有顏色——這正是真實終端的作法。

## 三、字體

| 場合 | 字體 | 字距 |
|---|---|---|
| 一切外殼（標題、標籤、按鈕、讀數、編號、時間） | `--mono` | 1–3px |
| 長篇內文（超譯內容、對白、劇情） | `--sans` | 0 |

規則：**機器說的話用等寬，人說的話用一般字體。** 這條線一旦模糊，沉浸感就散了。

最小字級 12px（乘上使用者的 `--fs` 倍率）。

## 四、效果

### 4.1 磷光暈 (glow)

磷光文字必須發光，否則就只是綠色的字。

```css
text-shadow: 0 0 8px rgba(126, 240, 168, 0.45);
```

金色與青色通道用各自的色相發光。

### 4.2 掃描線 (scanlines)

覆蓋**整個應用程式**，不只開機畫面。這是把所有畫面綁成同一台機器的關鍵。

```css
background: repeating-linear-gradient(0deg,
  rgba(126,240,168,0.045) 0 1px, transparent 1px 3px);
```

必須 `pointer-events: none`。

### 4.3 暈影 (vignette)

四角壓暗，模擬 CRT 曲面。全域一層即可。

### 4.4 角落方括號

面板的四角用 `::before` / `::after` 畫 L 形線段，不畫完整外框。這比實線邊框更像儀器面板。

## 五、元件

### `.term` — 終端面板
角落方括號 + 掃描線。所有主要覆蓋層都要套。

### `.term-title` — 面板標題
等寬、字距 2px、前綴 `▚`。

### `.cmd` — 指令按鈕
文字一律包在 `[[ ]]` 裡。這是下給機器的指令，不是給玩家的按鈕。

```
[[ 開始觀測 ]]   [[ 關閉 ]]   [[ 回收 ]]   [[ 歸檔 ]]
```

### `.src` — 出處聲明
每個面板都要說明自己是誰編的。這是沉浸感最便宜也最有效的一招。

> 來源：公開社群即時擷取 · 內容未經查證
> 本欄事蹟由各國教育部、宗教團體與演算法共同認定

### `.field` — 讀數列
`標籤 ······ 數值`，中間用點線連接。

### `.rec` — 超譯紀錄
歸檔文件格式：編號、時間戳、提交單位、原始觀測、該單位之推定、核定增額。

## 六、寫作口吻

介面文字一律用**公文與儀器的口吻**，不用遊戲口吻。

| 不要 | 要 |
|---|---|
| DAY 1 / 6 | 觀測第 1 日 / 6 |
| 末日倒數 | 協會風險評估 |
| 行動力 | 可支配時段 |
| 牌庫 / 棄牌 | 待用論點 / 已用 |
| 收割 | 協會撥付 |
| 你贏了！ | 對象已進入頓悟狀態 |
| 遊戲設定 | 終端校準 |

**免責聲明是本作的招牌語氣。** 協會永遠不為自己呈現的東西背書：

> 警告：本終端所呈現之一切結論，均為各學派依其專業所作之推定。
> 協會不對其真實性負任何責任。

這句話同時是世界觀、是笑點、也是遊戲機制的說明書。

---

## 七、禁止

- 不用 emoji 當作介面裝飾（作為**資料**的圖示可以，例如資源與學派）
- 不用圓角泡泡、卡通陰影、彩色漸層按鈕
- 不用「遊戲感」詞彙（關卡、經驗值、Game Over、恭喜通關）
- 不讓外殼出現學派色以外的彩色
- 內文不用等寬字（會變成滿屏程式碼，喪失可讀性）
